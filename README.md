## `01` — Sobre mim

Olá! Sou **José de Oliveira Prado Júnior**, estudante do primeiro semestre de **Análise e Desenvolvimento de Sistemas (ADS) na UNIP**.

Estou no início da minha jornada na tecnologia, construindo minha base em lógica de programação e aprendendo Python e JavaScript.

Tenho interesse em desenvolvimento Full-Stack, segurança de dados e computação em nuvem. Meu objetivo é evoluir tecnicamente, desenvolver projetos práticos e me preparar para minha primeira oportunidade como desenvolvedor júnior.

Não tenho pressa em parecer experiente. Quero aprender, praticar e construir uma base sólida.
